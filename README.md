# Etinosa Ekhator — Portfolio

A responsive portfolio built with React and Vite.

## Requirements

- Node.js 18 or later
- npm

## Getting started

```sh
npm install
npm run dev
```

Vite prints the local development URL in the terminal.

## Production build

```sh
npm run build
npm run preview
```

The optimized production site is generated in `dist/`.
